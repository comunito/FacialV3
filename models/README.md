# Model policy

The production pipeline is model-versioned. Every whitelist cache declares the exact `model_id` used to generate its embeddings; a cache generated by another model is rejected instead of silently producing invalid matches.

Current baseline:

- Detector: YuNet FP32, `face_detection_yunet.onnx`.
- Recognizer: SFace FP32, `face_recognition_sface.onnx`.
- Profile: `sface-2021dec-fp32-v1`.

The next candidate is the official OpenCV block-quantized SFace INT8 model. It must be benchmarked and its threshold recalibrated on the Raspberry Pi before becoming the default. It also requires regenerating every embedding; FP32 and INT8 embeddings must never be mixed.
